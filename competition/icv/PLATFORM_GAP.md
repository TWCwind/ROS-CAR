## 首个闭环的内部接口

| 环节 | 本仓库内部约定 | 正式适配前须核对 |
|---|---|---|
| 状态读取 | `VehicleState(x_m, y_m, yaw_rad, speed_mps)`；世界坐标、米、弧度、米/秒 | 平台位置是否为后轴中心；`oriZ` 单位和正方向；速度分量的坐标系与更新时间 |
| 目标路径 | 按行驶方向排序的世界坐标中心线点列 | `wayPoints` 的结构、坐标系、有效范围和场景是否提供 |
| 转向 | 前轮转角，弧度，左转为正 | 平台 `steering` 是方向盘角、前轮角还是归一化命令；符号、比例、限幅与执行延迟 |
| 纵向控制 | 油门、制动取内部归一化 0–1 | 平台油门/制动取值范围、制动模型、挡位与灯光枚举 |
| 循环 | 离线模型每步 0.05 秒 | 平台帧同步/异步模式、有效指令频率、时间戳及状态过期处理 |

## 当前缺口与下一步

1. 获取本届平台安装包、算法联调说明、Python/C++ 示例和准确的 SDK 版本；确认 Python 模块可导入、接口签名、字段与控制范围。
2. 在官方示例场景中读取一次真实主车状态与路径，保存去身份化的字段/单位核对记录，再实现 `SimOne → VehicleState` 适配。
3. 核对转向控制量含义与车辆轴距/转向比，先以低速在车道保持示例场景验证左右转方向，再实现 `ControlCommand → SimOne_Data_Control` 适配。
4. 取得实际场景评分报告，记录场景号、运行次数、得分、零分原因和修改前后数据。当前仅有离线几何/动力学模型结果，官方平台成绩为**未验证**。

## 已完成的离线闭环

`controller.py` 读取内部车辆状态与路线，生成局部目标路径、选择前视点，输出正向转向、油门和制动；`offline_demo.py` 用简化自行车模型执行输出，形成可运行的状态—控制—状态循环。运行：

```powershell
python -B competition/icv/offline_demo.py
```

离线示例覆盖 120 m 直道和半径 50 m 的弯道，起点带 0.25 m 横向偏差与 0.03 rad 航向偏差。模型没有传感器噪声、交通参与者、碰撞评分或赛事车辆动力学，因此结果仅用于发现算法基本错误。
